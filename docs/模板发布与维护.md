# 模板发布与维护

1. 打开“模板与填报”，在右上角选择预算年度和轮次。
2. 点击“发布填报模板”或“更新填报模板”，上传空白填报表，可填写便于识别的模板名称。
3. 点击“发布到当前预算版本”。检查通过后，项目即可下载；检查不通过时按提示调整。
4. 项目登录后下载自己当前开放版本的模板，填报后上传。下载文件会带上项目和预算版本，项目不能修改所属版本。

模板按预算版本管理，更新会保留旧文件和发布记录，已归档版本不能更换模板。项目名单来自该预算年度的适用项目范围。

允许增加或调整附表。当前四套汇总报表的科目、结构和计算公式仍须符合该版本已配置的财务规则；重新设计汇总报表时，需要同步配置其科目和计算关系，不能仅换一个下载文件。宏和外部数据连接需先移除。

请上传空白填报表。系统保留表内内容，不会替管理员判断并删除其中的项目数据；已经确认的历史数据按项目回填并校验。
