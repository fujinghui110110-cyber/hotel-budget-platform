# 2026.09.23.1 发布说明

本版包含年度预算目标、历史数据锁定、管理指标导入与对比、按预算版本发布模板，以及简化的一键启动入口。

## 数据与升级

代码包不包含业务数据库、已上传底稿或账号配置。数据库结构升级至 0016；升级前须完整备份数据库、上传文件、历史模板及配置。升级后的数据库不能交给旧版程序运行，不能用旧备份覆盖升级后的新增业务。

旧版先通过系统更新安装 2026.09.23.0 过渡版，再检查并安装本版。过渡版保留旧业务代码和数据库结构，仅准备后续在线升级；正式开放前须通过 Windows/macOS 隔离升级验收。

新版升级校验需要的工具可自动下载安装并校验，验证失败仍禁止安装。

## 验证边界

本机自动化测试和独立打包检查见对应提交的验收记录。Windows 自动化检查以 GitHub Actions 实际结果为准；Windows 实机、第二台电脑验收由使用方后续完成。源码发布不代表这些检查已经通过。
