# 预算版本与汇总调整

预算年度可逐年选择。以预算年度 T 为例，参考 T-3、T-2 两年的实际及 T-1 年预测，不固定为 2027 年。

## 日常操作

1. 管理员进入「预算版本」，创建并开放版本，例如 2027 R1。项目只能查看管理员开放的年度和版本，上传时由系统确定归属。
2. 项目下载统一模板，填写后上传；系统校验完成后，管理端在「项目预算」按版本查看各项目上传情况。
3. 在项目行点击「查看」浏览完整已解析报表；点击「导出 XLSX」导出单项目，或点击「一键导出全部项目报表 ZIP」。ZIP 含各项目报表和清单，未上传或无可用稿的项目会列出原因。原始及重算底稿从「项目预算底稿」导出。
4. 在「预算测算」选择版本、项目和汇总表，点击「打开汇总表调整」。浅金色输入格可直接改大数，公式行由系统计算。需要比较历史时勾选「显示前两年实际与今年预测」。
5. 填写调整说明，点击「保存并计算」，核对调整前后及变化额，再点击「下发项目」。项目端「调整任务」会列出重点手工修改及公式联动。

## 数据口径

- 最近一份校验合格的本版上传作为可用稿。最新上传如果正在处理或校验失败，管理端明确显示该状态，并注明报表采用的合格稿来源。
- 上一版本复制的历史基线不作为新版本项目已上传的证据。
- 汇总调整金额使用元，保留两位小数；比例使用百分数，差额为百分点。缺失数据显示「—」，不补零。
- 汇总表内部已识别的公式自动计算；从分表汇入的管理大数作为测算输入。尚无法可靠解释的公式不被猜测替换。
- 测算与原始上报预算分开保存。下发的是年度目标，项目据此完善月度及分表，重新填报。系统不会把年度改动自动平均分摊到月份或其他项目。
- 基线更新后需要重新基于当前可用稿调整；已有下发记录保留，重复下发不会重复生成任务。
