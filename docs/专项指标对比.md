# 专项指标对比

左侧“专项指标对比”独立管理宴会收入、餐厅收入、租赁收入、第三方能耗收入。沿用预算版本选择，历史起始年度可选，默认展示预算年前三年实际、前两年实际、上一年预测及本版本预算。

## 上传

1. 管理员进入“上传历年指标”，下载统一模板。每个文件包含同一年度、同一口径的项目数据。
2. 选择年度、实际/预测/预算、元/万元；预算口径另需选择同年度预算版本。默认单位为元。
3. 通过文件选择器上传 `.xlsx`，核对预览中的项目、全年、每月金额和缺数。公式只读已保存的计算结果，不运行宏或外部链接；缺少公式缓存时需先在 Excel 中计算并保存。
4. 确认后替换同年度、同口径、同预算版本整批专项指标。若已有批次，必须确认替换；未列出的项目不再使用旧批次数据。旧原件仍保留，可在最近导入中下载核对。

四个 sheet 名称、项目及月份表头保持模板格式。项目可新增，但四表项目名单应一致；既有深圳凯骊酒店账号与模板“深圳凯骊”自动关联。新增项目账号仍通过“组织与账号”维护。

## 图表与口径

月度折线和年度柱图可按项目、指标、元/万元筛选，刷新后保留选择。默认图表展示每期已读到的完整数据并标注覆盖项目数；不同覆盖范围不能直接同比。切换“四期共同项目”可查看同一批项目的严格比较。

项目明细保留所有期间的数据及来源。空白显示“—”，真实零值显示 0。全年已有数值但月份不齐时，可以参加年度比较，不参加完整月度比较。预算较预测的增长率仅在两期有数且预测不为零时计算。

专项预算模板有值时优先使用该模板；没有补充值时，优先自动读取该版本最近可用预算套表的以下来源：

| 指标 | 预算来源 |
| --- | --- |
| 宴会收入 | B3宴会厅中的餐饮收入 |
| 餐厅收入 | B1餐厅汇总中的餐饮收入 |
| 租赁收入 | 不含名酒损益汇总表中的租赁收入 |
| 第三方能耗收入 | 无可靠独立科目时明确提示，通过专项模板按预算口径补充 |

系统按表名、科目名称、年度和期间匹配，不使用固定行号或将相近费用当作收入。科目重复、缺失或尚未上传预算时提示原因，不补零。

项目账号只能查看自己关联的指标。全项目模板上传和整批原件下载仅限管理端。
