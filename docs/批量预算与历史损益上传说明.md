# 批量预算与历史损益上传

管理端新增“批量上传预算”和“历史损益数据”两个入口。

## 批量预算底稿

1. 选择要接收底稿的预算版本。
2. 一次选择多个项目文件，点击“识别项目并上传”。
3. 文件名必须包含系统登记的项目名称或独立的项目代码，例如“4、万宁福朋-2027年预算.xlsx”或“WNSP-2027年预算.xlsx”。
4. 系统先核对整批文件。无法识别、命中多个项目或同批重复项目时，显示原因，整批不上传；修改文件名或文件选择后重试。
5. 上传后按文件查看处理状态，处理完成即可在项目预算中查看和导出。最多100份、总量500 MiB；普通版本支持xlsx，历史演练版本另支持xlsm。

文件归属依据文件名。系统不会根据工作簿内部的项目文字改变归属，也不会执行宏。

## 独立历史损益数据

每个文件按文件名识别一个项目，上传时选择年度、实际或预测、报表口径和原表金额单位。年度不与某次预算版本绑定，以后年度可继续引用。

不要求固定模板、固定工作表位置或固定行号。系统动态识别科目及金额表头，按名称规范化、常见近义名称与相似度生成匹配候选。高置信且无歧义的科目预选；其他科目由管理员改选或保留“不导入”。

上传先预览、确认后生效。确认时完整替换该项目同年度、同数据口径、同报表口径的历史数据；旧确认记录和原件保留。未导入科目和读取问题在“数据审计”中单独列示。没有数值或公式无已保存计算结果的单元格保持缺失，不补成零。

历史来源独立于预算版本。系统将确认数据同步给该项目的未冻结预算版本，供总览、趋势、报表和预算测算使用；新上传预算也使用这些历史来源。尚无预算底稿时，可在历史数据页面直接查看已确认数据。冻结版本保持原样。

升级后，未冻结版本中原先由项目预算文件带入的实际/预测缓存停止作为历史来源；底稿原件保留。请管理员单独上传并确认正式历史损益。项目后续上传预算不再读取或校验历史输入表。

金额单位“元/万元”只影响金额指标。平均房价等单价按元读取；比率、单价和房间数不会把12个月数值直接相加。无足够依据时，年度值保持缺失并提示核对。
