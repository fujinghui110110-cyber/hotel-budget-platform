# 2026.09.23.0 在线升级组件过渡版

本版本供已有系统更新入口的旧版服务器使用。保留 v2026.09.14.1 的业务程序和数据库结构，只更新在线升级组件。

安装后网页恢复，再到“系统更新”点击一次“检查更新”，即可选择较新的业务版本。原有账号、预算底稿、数据库、配置及启动入口继续使用，无需重装。

缺少发布验证工具时会从官方来源自动下载安装，并校验固定的 SHA-256。后续业务版本还必须验证 GitHub 发布证明。下载凭据只需本仓库 Contents 与 Attestations 的读取权限，不需要写权限。

此过渡版保留为 GitHub latest，便于尚未升级的旧客户端发现。新版客户端会自动选择版本列表中较新的正式业务版本，不受 latest 标记限制。

上线依据为对应提交在 Windows/macOS 的自动回归、隔离升级和发布证明检查。Windows 实体电脑与第二台电脑的人工验收不在自动检查范围内。
